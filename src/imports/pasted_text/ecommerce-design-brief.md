DESIGN A COMPLETE, HIGH-FIDELITY, MODERN E-COMMERCE WEBSITE AND ADMIN MANAGEMENT DASHBOARD.

PROJECT OVERVIEW

Create a premium, professional, modern, visually attractive, and highly interactive multi-category e-commerce platform.

The platform should provide a smooth and trustworthy shopping experience similar to a major modern e-commerce marketplace. The design should be unique and should NOT directly copy any existing website.

The website will have four main product categories:

1. Sanitary Items & Bathroom Accessories
2. Hardware & Tools
3. Surgical & Medical Items
4. Household Products & Essentials

The complete project must include TWO major systems:

A. CUSTOMER-FACING E-COMMERCE WEBSITE
B. ADMIN / CLIENT MANAGEMENT DASHBOARD

The Admin Dashboard must be designed for a non-technical client who should be able to manage products, prices, stock, sold-out status, discounts, orders, banners, and other website content WITHOUT writing or editing any code.

* Disable Add to Cart
